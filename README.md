# DN Audio Privacy Policy

Public privacy policy site for **DN Audio**, the offline music player by Digital Native Dev.

## Published URL

After GitHub Pages is enabled, the expected URL is:

https://dedealmustaqim.github.io/dn_audio_privacy/

## Enable GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save, then wait for GitHub Pages to publish the site.
6. Open the published URL and verify it loads publicly over HTTPS.

## Policy contents

- `index.html` — English and Bahasa Indonesia privacy policy.
- `assets/styles.css` — responsive monochrome presentation.

## Important release verification

The policy is based on the DN Audio implementation reviewed during release preparation. Before submitting a production build to Google Play, verify the final merged Android manifest and the complete direct/transitive dependency and SDK inventory. Update the policy and Google Play Data safety declarations if the final app or any included SDK collects, transmits, or shares data.

The public policy URL must also be entered in Google Play Console and made accessible from inside the app. Confirm the published URL and in-app link before release.
